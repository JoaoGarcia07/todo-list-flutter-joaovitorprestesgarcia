Este projeto é um aplicativo de Lista de Tarefas (To-Do List) interativo desenvolvido para a disciplina de Desenvolvimento para Dispositivos Móveis da Faculdade Senac Joinville.

**Estudante:** João Vitor Prestes Garcia
**Turma:** 5ª Fase ADS 2026

## 🚀 Funcionalidades Implementadas
* **Adicionar Tarefas**: Campo de texto e botão para inserir novos itens.
* **Exibir Lista**: Visualização dinâmica e organizada com scroll.
* **Marcar como Concluída**: Checkbox que risca o texto ao finalizar a tarefa.
* **Remover Tarefas**: Botão de exclusão para cada item da lista.
* **Feedback de Progresso**: Contador mostrando tarefas totais e concluídas.
* **Interface Pastel**: Design moderno utilizando cores suaves e Material 3.

## 🛠️ Requisitos Técnicos
* Implementação de classe de modelo `Tarefa`.
* Uso de `StatefulWidget` e gerenciamento de estado com `setState()`.
* Manipulação dinâmica de `List`.
* Uso de `TextEditingController` com gerenciamento de memória (`dispose`).
